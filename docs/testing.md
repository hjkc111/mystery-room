## 验收矩阵

| 范围 | 断言 |
|---|---|
| 四角色×九阶段 | 正文章节、调查对象、证据权限正确，别人秘密不出现 |
| 第一轮 | 先个人材料；非法/重复调查不扣点；公共对象可分别查 |
| 讨论 | 每人实际出示；别人公开同一卡不能代替本人 |
| 第二轮 | 四材料唯一领取；重复拒绝且不扣点；能合作收齐 |
| 最终陈述 | 自动公开四复核，不自动刷个人出示成就 |
| 指控复盘 | 票向隔离、改票、到期拒绝、正确/错误/平票/零票、全部原文 |
| 私密交流 | 公聊广播、私聊仅双方、笔记仅本人；终幕保持聊天隔离 |
| HTTP身份 | 无会话、外源、非成员、伪造参数、超长输入、敏感资源拒绝 |
| CAS去重 | 同版本并发一写成功；相同requestId并发及重放不重复执行 |
| 持久化 | 刷新/新Worker实例后保留D1进度和Cookie身份 |
| 房主 | 权限、暂停、恢复、延长、离线阈值与接管 |
| AI | 配置协议、授权材料、无Key/429/超时/坏响应回退 |
| 浏览器 | 四隔离身份点完流程，移动布局、断网恢复、控制台错误 |

## 独立全局路线

建立四套Cookie身份，一人创建其他加入，各选不同角色。通过真实动作推进，不直接修改phase跳幕。每阶段同时核对四人正文与权限。第一轮保留私有线索并公开其他线索，发送私聊并保存笔记；第二轮分配领取且尝试重复请求；四人投票并检查全部证据及个人结果。另开第二房间核对隔离。

网络重放与并发需真实HTTP请求，不能只调用act()。浏览器本地多上下文能验证页面链路，不能证明异地运营商网络表现。
