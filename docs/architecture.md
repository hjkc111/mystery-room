# 当前架构与同步

目标版本：Cloudflare Worker `fetch` 入口、D1 持久化、原生 HTML/CSS/JavaScript，由 Sites 发布。当前验证状态见[实现状态](implementation-status.md)。

```text
浏览器 Cookie 身份
  ├─ GET /api/state（约 450 ms）→ 当前玩家授权快照
  └─ POST /api/action（动作、requestId、expectedRevision）
         → 身份/阶段校验 → game.mjs 在副本执行规则
         → D1 按旧 revision 条件更新（CAS）→ 新授权快照
```

## 状态与并发

服务器是唯一裁判。保留 `server/game.mjs` 和 `server/case.mjs`，Worker 负责会话、网络、存储及响应。客户端按钮禁用不能代替服务器校验。

D1 条件更新必须保证多个 Worker 读到同一版本时只有一个写入成功；失败操作不得扣点或计票。请求 ID 完成记录与状态原子保存，相同请求重复到达不得重复执行。去重与 CAS 是不同检查，都要测试。网络超时不意味着服务器未执行；冲突应提供最新授权状态并让玩家重试。

Worker 没有常驻进程。房间、会话和必要活动时间保存在 D1，不能用内存连接表判断在线或恢复进度。倒计时使用服务端持久化 deadline；Worker 换实例不等于游戏重启，不应沿用旧 Node 进程重启自动暂停。

## 同步延迟

450 ms 是 HTTP 回退轮询间隔，不是延迟保证。网络、后台标签页节流和请求执行时间会增加延迟；慢网不能堆积无限状态请求。操作人可立即应用操作响应，其他人等待下一次轮询。房主接管需以持久化最近活动时间判定并单独测试。

## 权限

- Cookie 绑定高熵身份，不能凭请求内 playerId 冒充别人。
- 游戏中仅发送本人已解锁章节、私有线索和全桌公开线索。
- 私聊仅双方、笔记仅本人；结算前不广播选票内容。
- 调查同时校验角色、阶段、点数和已得材料。
- 终幕开放案件真相和全部证据，不因此公开私聊及笔记。
- 静态入口不暴露环境文件、服务端源码、D1 数据和密钥。

公开 GitHub 含答案，因此这里保护正常网页流程，不防止朋友到仓库查剧透。

## AI

服务端将提问者视图裁剪为当前章节与已知证据，再调用 Chat Completions。不发送他人私密章节或未公开答案；玩家输入不当系统指令。AI 输出是辅助说明，不是新证据，也不能修改阶段、行动点或票数。

默认 `deepseek-flash`，地址、模型、超时、输出长度和每房预算可配置；无 Key 和接口错误回退规则提示。模型仍可能误述或推断已有材料，提示词不是绝对防剧透保证。

## 历史区别

旧版 Node/ws/本地 SQLite 的 WebSocket Upgrade、持久卷、单进程锁和重启暂停说明不适用。历史内容见[initial-design.md](initial-design.md)。

## 存储与一致性细节

D1绑定名DB，schema在db/schema.ts，迁移在drizzle目录。rooms存阶段和角色快照；seats存成员和活动时间；sessions存Cookie哈希；messages单独存聊天，避免D1单行大小上限；limits记录请求频率。聊天插入与房间CAS、入席记录与成员CAS分别在同一个D1 batch内按changes()条件执行。

去重保留最近512个成功请求；更早重放仍携带原revision并被CAS拒绝。客户端仅在服务器明确拒绝且阶段未变化时，应用新快照后重试一次，不重放结果未知的请求。AI保存每人最近一次请求状态和回答，可用同requestId恢复已保存回答；中断前未完成的模型调用不自动重复扣费。当前没有前端恢复AI历史入口。

每5秒左右更新活动时间，20秒未活动显示离线，60秒允许接管房主。客户端串行轮询，不堆积请求；请求超时会退避重试。

## 2D 位置同步

浏览器之间通过 WebRTC DataChannel 发送位置（上限 20 Hz）及刷新通知；D1 中的 signals 仅作已认证成员间的信令交换。坐标不携带秘密文本，也不能替代服务器权限。world-map.js 是共享地图、碰撞和阶段开放数据，server/world.mjs 裁决移动与现场操作。

浏览器每约 300 ms 上传一批轨迹，顺序号阻止乱序覆盖，服务器按路径长度、速度、墙体、阶段和门距离校验。positions 与游戏 revision 独立，游戏动作 CAS 不会被走路持续抢占。会客室入场容量在单次 SQL 条件写入中检查。超过 20 秒未刷新位置后回到本幕出生点，切幕同样复位。

位置直连失败自动回退 HTTP；本地预估不等待往返，远端插值。无 TURN，因此不能保证跨运营商低延迟。完整方案和实测边界见 [2D 方案](2d-scene-plan.md) 与 [测试报告](2d-scene-test-report.md)。
